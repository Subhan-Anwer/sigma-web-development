CSS Position Property

See how each position value changes the placement of elements

Static Default

Elements are placed in the normal document flow. Top, left, right, bottom properties have no effect.

Box 2 (static)

Relative

Element stays in the normal flow but is shifted from its original position using top, left, right, bottom. The original space is still preserved.

Box 1 (static)
Box 2 (relative — moved 30px down & 40px right)
Box 3 (static — stays in place, gap preserved)

Absolute

Element is removed from the normal flow and positioned relative to its nearest positioned ancestor (the grey box below has position: relative).

Parent (position: relative)

Box 2 (absolute — top: 10px, right: 10px)
Box 3 (static — acts like Box 2 doesn't exist)

Fixed

Element is removed from the flow and positioned relative to the viewport. It stays in the same spot even when you scroll. Look at the "I'm Fixed!" badge at the bottom-right corner — it never moves!

Sticky

Element behaves like relative until you scroll past it — then it sticks to the given position (like fixed). Scroll inside the box below to see it in action.

When positioned elements overlap, z-index controls which one appears on top. Higher value = closer to you.
